# Historical skill evidence

These records describe pre-0.2.0 evidence for the superseded four-skill design.
They are retained as historical context. They do not verify the current
three-skill inventory, current instructions, current client behavior, or a
0.2.0 release. See `../docs/requirements-to-evidence.md` for pending current
acceptance work.

Add current evidence only after root runs the check and independently inspects
the exact artifact and result. Record the command, version, source/target
identity, and receipt; do not convert missing or historical evidence into a
pass.

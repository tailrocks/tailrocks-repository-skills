# Model choices

Use the [bundled model guide](../skills/tailrocks-review-pr/references/model-routing.md)
when a request names a model or effort or gives you a choice of route. It records
provider model IDs and the controls documented for each surface. Account access,
live host catalogs, subagent settings, and effort caps determine the available
route. An ID in the guide does not prove its availability in your session.

Keep the current model and reasoning settings for ordinary work. Preserve an
explicit model version, variant, effort, or service tier for the role it names.
Use documented session controls. Keep persistent host settings in place.

When authorized to choose a route, choose a capable model with an economical
supported effort. Prefer `medium` or the documented balanced equivalent for
ordinary work. Verify the model and effective effort when the host exposes them.
Report an unavailable selector or unverified effective setting. Keep all
approval and role boundaries from the selected skill.
